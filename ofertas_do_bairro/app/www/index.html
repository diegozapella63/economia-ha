    Itens da lista

    Uma lista só para farmácias, mercados, pet shops e compras online. O que está acabando aparece primeiro. Toque em "Comprei hoje" quando comprar: o painel aprende de quanto em quanto tempo cada coisa acaba.

      Lojas perto de casa

      Encontradas pelo seu CEP, de rede ou independentes. Desmarque uma loja para não ver mais as ofertas dela, ou marque uma mais longe para acompanhar também.

      Clubes e contas

      Com login, aparecem os cupons e preços que cada clube dá só para você.

        A busca usa o que as lojas publicam para todo mundo. Os cupons pessoais dos clubes, que pedem login, ficam para uma próxima versão.
